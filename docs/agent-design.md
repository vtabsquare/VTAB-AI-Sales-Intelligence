# Agent design
Supervisor: coordinates qualify → research → capability match → contact → outreach. The workflow persists completed steps and outputs. Errors leave FAILED with completed checkpoints intact. A retry skips completed tools. A reviewed qualification can rerun a REVIEW_REQUIRED workflow. An explicit rerun can reclaim a RUNNING workflow after a 15-minute lease; no autonomous outbound action occurs.
Discovery: demo fixtures or live configured connectors; preserves source URLs and source occurrences, normalizes tracking URLs and avoids repeated same-source/title opportunities. Fuzzy/semantic duplicate adjudication is future work.
Qualification: seven bounded score dimensions, hard gates, confidence, concerns and reasons. Demo/local rules are clearly identified; live semantic evaluation requires AI_PROVIDER=openai or azure and a configured endpoint/key/model. Hard deterministic rejections and approved-capability checks override model scores.
Research/contact: source-evidence retrieval; no invented addresses; published candidates remain unverified. Demo evidence is synthetic and labeled.
Capability match: retrieves approved knowledge only. DEMO-category knowledge is excluded when DEMO_MODE=false. A document approval is a human assertion of reviewed company facts, not an external authenticity check.
Outreach: builds a personalized local draft or validated provider output from approved knowledge; never sends. Provider requests use separate Markdown system prompts, bounded input, strict JSON schema and Pydantic validation. All external content is untrusted data. Follow-up/response agents from the prior implementation are retained for later acceptance.
